# Solana Devnet Faucet 🚀

A simple faucet to request test SOL on Solana Devnet for development and testing.

### Features
- Connect your Solana wallet
- Request test SOL
- Check wallet balance
- View transactions on Solana Explorer

### Tech Stack
React · TypeScript · Tailwind CSS · Solana Web3.js

### Getting Started

```bash
git clone https://github.com/Ketan1317/SOL-Faucet-AirDrop.git
cd SOL-Faucet-AirDrop
npm install
npm run dev
```

**Note:** This project uses Solana Devnet. Test SOL has no real-world value.
